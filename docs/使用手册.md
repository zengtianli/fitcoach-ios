# 私教课时 · 使用手册

装在 iPhone 上的那个「私教课时」。数据和网页版 <https://fit.tianli.cyou> 是同一份，
手机上改完，网页刷新就能看到。

---

## 0. 第一次打开

1. 主屏点「私教课时」。若提示**不受信任的开发者** →
   设置 → 通用 → VPN 与设备管理 → 开发者应用 → 你的 Apple ID → 信任。
2. 上面两个格子选 **教练登录**，输网页端那个邮箱 + 密码。
3. 登录一次就记住了，之后打开直接进日程。（换手机或退出登录才要再登。）

> 「学员查看」那一格是给学员用的，你不用点。

---

## 1. 三分钟把账本建起来（只做一次）

按这个顺序，不然后面会卡住 —— 排课要先有课包，课包要先有学员。

| 步 | 去哪 | 做什么 |
|---|---|---|
| ① 地点 | 更多 → 上课地点 → 右上 `+` | 填工作室名字。**可以跳过**，排课时地点允许「不指定」 |
| ② 档期 | 档期 → 右上 `+` → 加每周规则 | 每个能上课的星期各加一条时段，比如 周一 09:00–21:00。**建议做**，做了以后排课会提示「这个点不在档期」 |
| ③ 学员 | 学员 → 右上 人+ 图标 | 填姓名。备注只有你看得见 |
| ④ 课包 | 学员 → 点开这个人 → 右上 `⋯` → 加课包 | 买了几节、多少钱一节、买的日期。到期日可不填 |

做完 ③④ 就能排课了。

## 2. 日常就三件事

### 排一节课
日程页右上 `+` → 选学员 → 课包自动选好（先到期的先用）→ 定日期和起止时间 →
选地点 → 写上课内容 → **排这一节**。

- 时间那一栏下面会显示「当日可排 09:00–21:00」，那是你自己设的档期。
- 如果撞课了 / 不在档期 / 超出剩余节数，会弹一个确认框把原因写清楚，
  你确认要排就点**强制排入**。
- 有些情况是**拦死的**，弹不出强制：比如课包已经作废了、或者把一节**未来**的课
  直接标成「已上课」。这时候会直接报错说原因，那不是 bug。

### 上完课点两下
日程页**点那一行课** → 选「已上课」→ 保存。剩余节数当场就扣了。

- 从「已排课」改成任何状态，**不用填理由**。
- 时间过了你还没标的课，会显示成橙色的**待处理**，日程顶部也会有红点提醒。

### 学员问「我还剩几节」
学员 tab 直接就能看到每个人的可用节数。要给他自己查的话见第 4 节。

## 3. 四个标签页里各有什么

### 日程
- 上面三格切 **今天 / 本周 / 过时**。「过时」= 时间已经过了但你还没标状态的课。
- `‹` `›` 前后翻（今天视图翻一天，本周视图翻一周），中间「回到今天」。
- **点一行** = 改状态。**手指往左划一行** = 改课（改时间/地点/内容/课包）。
- 顶上「提醒」区是自动算的：过时未处理、余额不足、课包快到期。

### 学员
- 上面能搜名字。分「在册」和「已停用」两段。
- 点进某个人：余额、学员端链接、课包（按可用/已过期/已用完/已作废分组）、全部课次。
- 右上 `⋯`：改资料 / 加课包 / 给这个人排一节课。
- **课包那一行**：点 = 改（节数、单价、日期、备注）；**左划** = 作废 / 撤销作废。
- **课次那一行**：点 = 改状态；左划 = 改课。

### 档期
- **每周规则**：常规每周哪几天、几点到几点能排课。左划删。
- **例外**：某一天特殊。「停排」可以整天（比如出差），「加开」必须给时段。例外压过每周规则。
- **未来两周**：算好的结果，直接看每天实际能排哪些时段。

### 更多
上课地点 / 变更记录 / 改服务器地址 / 退出登录。

## 4. 学员那头怎么用

在学员详情页 → 「学员端链接」那一段：

| 按钮 | 作用 |
|---|---|
| 签发学员链接 | 第一次用，生成一条链接 |
| 分享 / 复制 | 发微信给学员 |
| 重新签发 | 生成新链接，**旧的立刻失效** |
| 吊销链接 | 学员再打开就是 404 |

学员拿到链接后有两种用法：

- **直接在微信里点开**就能看（网页版，什么都不用装）；
- 或者他也装这个 app，登录页切到「学员查看」，把链接粘进去。

学员能看到：剩余课时、下一节课、上课记录、被取消的预约。
**看不到**：价格、你写的备注、变更记录、别的学员 —— 这是代码结构上保证的，不是靠自觉。

> ⚠️ 链接就是凭证，谁拿到谁能看。怀疑发错人了 → 点「重新签发」，旧链接当场作废。

## 5. 真实情况怎么处理

| 情况 | 怎么点 |
|---|---|
| 学员请假，提前说的 | 点那节课 → 已取消 → 原因分类选「学员请假」。**不扣课时** |
| 学员没来也没说 | 点那节课 → 未到 → **照扣 1 节** |
| 放了鸽子但你想通融 | 先标「未到」，事后点开 → 改成「已取消」→ 必须填理由 → **退回 1 节** |
| 标错了 | 点开改回去，填理由。每次改都留痕，改不坏 |
| 补录以前上过的课 | 排课时把「建课状态」直接选「已上课」，日期选过去那天 |
| 学员要退课 | 学员详情 → 左划课包 → **作废**。包里还没上的课会一起取消，不扣节 |
| 课包买 10 节上了 12 节 | 允许，余额显示负数。学员那头显示 0 并单独提示「已超上 N 节」 |
| 学员不练了 | 学员详情 → `⋯` → 改资料 → 关掉「在册」。**注意这会同时吊销他的链接** |

**扣不扣课时，一句话记住**：已上课扣、未到扣、已取消不扣。

## 6. 出问题了

| 现象 | 原因 / 怎么办 |
|---|---|
| app 突然打不开 | **免费证书 7 天到期**了，数据没事都在服务器上。找我重装一次即可（不用插线，走 WiFi） |
| 打开显示登录页，之前明明登过 | 会话过期或密码改过，重新登录 |
| 转圈半天没数据 | 手机没网，或服务器在重启。下拉刷新试试 |
| 学员说链接打不开 | 多半是被吊销/重新签发过了，重新发一条给他 |
| 排课报错说不出为什么 | 报错原文就是原因（比如「课包已作废」）。这些是拦死的，不能强制 |

任何一页都可以**下拉刷新**。

## 7. 三条别踩的

1. **停用学员会连他的链接一起吊销** —— 只是暂时不练，不如别停用，留着就行。
2. **「强制覆盖」不要养成随手勾的习惯** —— 它每次都是不勾的状态，是故意的。
3. **改状态填的理由会永久留档**，学员看不到，但将来对账时就靠它。

## 8. 成长数据（给家长看的那部分）

这是让家长看见「孩子在变好」的地方。逻辑只有一条：**跟自己比**，不跟别的孩子比。

### 先建体测项目（只做一次）

更多 → 体测项目 → **一键灌默认项目**。会直接给你八项，一把尺一块秒表就能测：

身高 · 体重 · 立定跳远 · 坐位体前屈 · 50 米跑 · 1 分钟仰卧起坐 · 引体向上 · 平板支撑

不合适就改，不用的停用（停用不删，历史成绩要保持可读），也可以自己加。

**加自定义项目时有一个必填项别选错：「越大越好 / 越小越好」。** 立定跳远是越大越好，
50 米跑是越小越好。选反了，孩子跑快了会被显示成退步。

### 录成绩

学员详情 → 成长 → 录一条成绩：选项目、选日期、填数字。

- **同一个孩子、同一个项目、同一天只留一条**。当天重测就是改那一条，不会并存两条。
- **0 是有效成绩**（引体向上 0 个），空着不填才是「没测」。别用 0 代替没测。

### 家长看到什么

学员端链接里会多出「成长」一段，显示：**最新成绩 + 比第一次变化了多少 + 测了几次 + 趋势线**。

- 显示的是「立定跳远 比第一次 +13cm」这种人话，不是一堆原始数字
- **测量备注永远不给家长看**（和学员备注同一道防线，是代码结构上做掉的，不靠人记得别写）
- 只测过一次的项目不显示"进步/退步"，因为还没有变化可言

### 怎么用它续费

课包快用完的时候，把成长这一段发给家长，比说十句话管用。三个数就够：
**练了多少节 · 到课率 · 哪几项进步了多少**。

如果某一项在退步或者没动，别藏着——直接说下阶段打算怎么练。家长要的是有人在认真看着，
不是每项都好看。

## 9. 账号与安全

### 改密码

更多 → 修改密码。**要输原密码**（只凭手机上已登录的状态就能改的话，手机被人拿到一次
就等于账号永久易主）。

改完**其它设备不会被踢下线**，网页端那边如果登着还是登着。

### 忘记密码怎么办

**没有自助找回。** 这个系统不会发邮件。密码定完请存进密码管理器；真忘了只能找我进库改。

### 登录会被限速

同一个账号 15 分钟内连错 5 次就会被锁一段时间，正确密码在锁定期内也进不去。
这是防爆破的，你自己万一连错几次，等一会儿就好，页面会告诉你还要等多少秒。
